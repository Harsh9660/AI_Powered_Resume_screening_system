# AI_Powered_Resume_screening_system
AI-Powered Resume Screening System that parses PDF resumes into structured data and ranks candidates using NLP-based job matching and XGBoost/LightGBM models. Includes hyperparameter tuning with Optuna, evaluation using F1-score &amp; Precision@K, SHAP explainability, and FastAPI deployment for real-world hiring workflows. 🚀
